# RedArc-TVMS-Prime-Tank-Sensor-using-Mopeka-Pro-Optocoupler

This repo enables you to build a module for your RedArc TVMS Prime that will convert the incoming Bluetooth data from up to six Mokepa Pro Universal tank sensors into sensor probe output compatible with your RedArc TVMS Prime water tank sensor inputs.

This repo contains two Arduino IDE files:

1. The RedArc TVMS Prime Tank Sensor using Mopeka Pro via Optocoupler IDE
2. A Mopeka Pro Bluetooth MAC Scanner tool IDE

The main IDE contains instructions on wiring and configuration.

The MAC scanner is required to identify the unique Bluetooth MAC address of each of your Mopeka Pro devices.
